# Sharmin Akter — Multi-page CSE Portfolio

## Pages
- `index.html` — Home
- `about.html` — About, education and learning journey
- `skills.html` — Skills and skills table
- `projects.html` — Academic and practice projects
- `contact.html` — Contact details and form

## Run
Extract the ZIP and open `index.html` in Chrome or Firefox. For the AJAX contact-form demonstration, run the folder through VS Code Live Server and keep an internet connection available. The form posts test data to JSONPlaceholder; it does not deliver email or store a real enquiry.

## Files
`style.css` contains shared responsive styling; `script.js` contains navigation, scroll interactions, validation and the AJAX demo; `assets/sharmin-akter.jpg` is the existing profile image.
